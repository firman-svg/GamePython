    Cara Menggunakan Smart Rapor Analyzer

    1 Tambah Mata Pelajaran

    Klik tombol "Tambah Mapel" untuk menambahkan mata pelajaran baru. Isi nama mata pelajaran dan nilai untuk 5 semester.

    2 Input Nilai

    Masukkan nilai untuk setiap semester (0-100). Nilai akan divalidasi secara otomatis dengan warna berbeda: Hijau (≥85), Kuning (70-84), Merah (<70).

    3 Analisis Data

    Klik tombol "Analisis Nilai" untuk memproses data. Sistem akan menghitung rata-rata, tren, dan memberikan rekomendasi.

    4 Lihat Hasil

    Periksa hasil analisis di bagian "Hasil Analisis", termasuk grafik perkembangan, rekomendasi AI, dan pencapaian.

    5 Fitur Aksesibilitas

    Aktifkan fitur aksesibilitas di pengaturan untuk Voice Navigation dan Screen Reader Mode.

    Tips: Gunakan data contoh untuk mencoba fitur aplikasi. Simpan template untuk analisis berulang.
